# Ключи — ипотечный калькулятор

Калькулятор «По бюджету» показывает, какую ипотеку можно взять и на какую квартиру хватит денег. Платёж, переплата и графики обновляются при изменении зарплаты, накоплений или условий кредита.

## Запуск

Нужны Node.js 22.18 или новее и npm. Команды запускаются из корня проекта.

```sh
npm ci
npm run dev
```

Откройте [http://127.0.0.1:8080](http://127.0.0.1:8080). Изменения исходников видны после обновления страницы. Команда `npm run build` собирает статическую версию в `dist`.

В разделе «По бюджету» укажите зарплату, долю зарплаты на руки для ипотечного платежа, текущие накопления и число месяцев подушки. Поле «Накопления» можно оставить пустым, чтобы увидеть, сколько денег понадобится на взнос и подушку. Ставка, срок и минимальный взнос настраиваются в разделе «Условия кредита».

В необязательном разделе «Досрочные платежи» можно указать дополнительную сумму из зарплаты на погашение долга с первого месяца. Карточка «Сколько отдадим банку» показывает экономию процентов и времени относительно кредита без ежемесячных доплат. Оба графика учитывают выбранное условие погашения из подушки.

Кнопка «Ссылка» копирует адрес текущего расчёта. При открытии ссылки калькулятор восстанавливает параметры бюджета. Значения записываются после `#` и доступны получателю ссылки.

```sh
npm run check
npm test
```

## Расчёт

- `src/mortgage.ts` экспортирует чистую функцию `calculateMortgage` и группировку графика `summarizeSchedule`. Денежные значения передаются в рублях, ставки в процентах, срок в месяцах. Внутри графика суммы округляются до копеек.
- `src/affordability.ts` экспортирует `calculateAffordability`. Функция считает максимальный кредит при заданном ежемесячном бюджете и минимальном взносе. Первый взнос равен накоплениям за вычетом подушки. Подушка покрывает заданное число платежей по ипотеке, её сумма округляется вверх до рубля. Интерфейс показывает расходы на сделку отдельной суммой.
- `src/salary.ts` рассчитывает удержания НДФЛ нарастающим итогом с января по декабрь. Для режима «До НДФЛ» калькулятор использует среднюю зарплату после налога и показывает удержания, ипотеку и остаток по месяцам. Модель предполагает одинаковое ежемесячное начисление обычной зарплаты налогового резидента РФ без вычетов. [Шкала НДФЛ за 2026 год](https://www.nalog.gov.ru/rn64/news/activities_fts/16639359/)
- `src/scenario.ts` переводит параметры покупки в параметры кредита. Здесь заданы рыночный ориентир, базовые условия семейной ипотеки, расходы на покупку и модель изменения ставки.
- Подушка может пойти на досрочное закрытие кредита. На странице бюджета можно посмотреть таблицу платежей по месяцам или годам и скачать её в CSV.

Начальная ставка 18% — средняя по фактическим рыночным выдачам за сентябрь 2026 года. [Обзор Банка России](https://www.cbr.ru/Collection/Collection/File/62505/mortgage_lending_market_2609_77.pdf)

## Какие калькуляторы изучены

- Банки.ру показывает ежемесячный платёж, сумму кредита, переплату, общую выплату и график. [Калькулятор Банки.ру](https://www.banki.ru/services/calculators/hypothec/)
- КонсультантПлюс позволяет выбирать тип платежей, задавать изменение ставки и вводить досрочные платежи. [Калькулятор КонсультантПлюс](https://calc.consultant.ru/mrg)
- Сбер описывает расчёт ставки, суммы кредита, необходимого дохода и платежа по параметрам ипотечной программы. [Описание калькулятора Сбера](https://www.sberbank.ru/retail/ru/person/credits/home/ipotechniy-kalkulyator)
- Домклик описывает расчёт на основе ипотечной программы, суммы, срока и первоначального взноса. [Страница ипотеки Домклик](https://domclick.ru/ipoteka)
